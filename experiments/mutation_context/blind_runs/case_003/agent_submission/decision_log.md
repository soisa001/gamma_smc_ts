# Decision log

## 1. Initial scope and plan
Read only the six supplied case files. The task is a probabilistic one-transmission allele forecast on circular, error-free haploid sequences. The calibration provides approximately four million bases and the target approximately one million. I will test baseline substitution rates, local sequence context, wider context and scaffold/position heterogeneity using independent held-out scaffolds. All random sampling uses seed 0. No withheld outcomes or external biological references will be used. Input files will remain unchanged.
## 2. Initial evidence and validation partition
The 80 calibration scaffolds each contain 50,000 bases; 19,987 sites changed (0.00499675). The 20 target scaffolds also contain 50,000 bases each. Scaffold heterogeneity is consistent with a common average rate (chi-square p=0.685); exploratory positional phases show no compelling signal after considering the number examined. Centered 5- and 7-base contexts improve held-out mutation log loss. Top 7-base contexts share the first six letters while tolerating any final letter, suggesting an asymmetric six-base rule spanning offsets -3 through +2. This is a hypothesis, not assumed knowledge.

Seed-0 scaffold permutation fixed a 48-scaffold training / 16-scaffold development / 16-scaffold audit split. No audit scores have yet been inspected. Initial descriptive summaries used all calibration data, so the audit is protected from parameter/model-selection scores but not strictly untouched by exploratory summaries. Next I will compare asymmetric windows and mutation-versus-destination smoothing.
## 3. Window selection and richer uncertainty models
A systematic development comparison of every contiguous context containing the focal base, of length 1 through 7, selected offsets -3 through +2. With simple separate shrinkage, its development four-allele log loss is 0.035204 versus 0.037871 for a parent-base-only model. Longer windows reduce performance. The selected six-base contexts have strongly heterogeneous mutation rates and often strongly preferred destination alleles. I will compare data-estimated beta-binomial, logit-normal and nonparametric rate priors, together with symmetric Dirichlet and mixture priors for destination probabilities. These model families are fitted using training counts and compared on development scaffolds; audit outcomes remain unused for scoring.
## 4. Final model selection frozen before audit
The logit-normal rate prior plus symmetric Dirichlet destination prior gives development log loss 0.0351630. A nonparametric rate mixture gives 0.0351624, a negligible 0.0000006 advantage. I choose the smoother logit-normal model to avoid unnecessary flexibility. Its training-fitted logit-rate mean is -5.6669, standard deviation 0.8531, and per-destination Dirichlet concentration 0.5422. A flexible destination mixture did not improve development loss. The final model family is now frozen: forward-oriented circular six-base context (-3..+2), empirical-Bayes logit-normal rate, independent symmetric Dirichlet destination proportions. Next, refit on the 64 training+development scaffolds and score the 16 audit scaffolds once, then refit on all calibration for target predictions. Audit results will be reported without tuning the model to them.
## 5. Audit results and production output
The frozen model, fit to 64 scaffolds, predicted 3,994.139 changes on the 800,000-site audit set, where 3,989 occurred. Its four-allele log loss was 0.03438183 versus 0.03688424 for a constant-rate/uniform-destination baseline. The fixed-smoothed sixmer model was effectively tied (0.03438115); I retained the already selected family. Audit rate-decile calibration shows imperfect spread, with some overprediction at high predicted rates; no audit correction was fitted.

Refitting on all calibration data gives an expected 5,000.441186784352 changes across the 1,000,000 unique target queries. The final TSV was written, read back, and checked for finite nonnegative probabilities, exact query identity/order, and normalized rows. Maximum serialized row-sum error is 5.21e-13. An independent scalar modular-indexing check passed at 19,898 sampled/boundary contexts. Input hashes were unchanged during finalization, and output SHA-256 was independently checked. Detailed methodology, caveats, exact parameters, validation metrics, and reproduction commands are in REPORT.md. No plots or external data were used.
