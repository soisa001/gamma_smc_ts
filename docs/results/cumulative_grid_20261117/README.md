Cumulative posterior-weighted mass at 500 kb, over 1,000 fixed pairs. Each replicate contributes one detection if any 1-kya cutoff inside the closed selection window has strict pointwise p < alpha. The empirical rank is (1 + number of reference values at least as large) / 101. Selected, test, and reference focal alleles segregate in the present-day population. The independent 50-kya de novo neutral bank serves both windows beginning at 50 kya. The ongoing 50-kya s=0.01 groups are excluded for both origins because retained alleles were usually near fixation. Rates are conditional on segregation.
