# EAS causal-site selection array

All 72 treatments reached 100 retained simulations. Of the 7,200 scored histories, 782 ended with the causal allele fixed. At the strict pointwise 0.05 threshold, selection at s = 0.01 from 10 kya to present was detected in 32 of 100 de novo histories and 15 of 100 introgression histories. With the same coefficient acting from 50 kya to present, detection reached 100 and 94 of 100, respectively. When selection ended at 30 kya, detection was 19 and 17 of 100.

The full replicate counts and denominators at both thresholds are in [power.tsv](power.tsv) and [fpr.tsv](fpr.tsv). Figures include [the 0.05 heatmap](heatmap_0.05.pdf), [the 0.01 heatmap](heatmap_0.01.pdf), [power across strengths](power_by_strength.pdf), and recent-onset allele-frequency trajectories for both origins at s = 0.01 and s = 0.03. Each figure is available as a PDF and PNG.

Every focal allele enters EAS 50,000 years before present at coordinate 500,000 bp in a 1-Mb region. De novo starts in one copy. The introgression model introduces approximately 1% donor haplotypes at the pulse with the focal allele present on all donor haplotypes. The archaic split is at 500 kya. The EAS population-size history, 25-year generation, rates and Gamma-SMC binary match the preceding strength series.

The 72 treatments cross two origins, selection during 10 kya–present, 50 kya–present or 50–30 kya, and coefficients of 0.001–0.010 in steps of 0.001, plus 0.020 and 0.030. Each independent replicate slot retries whole histories from 50 kya until the focal allele has at least one copy in the present-day EAS population. Fixations continue under the demographic model to the present. The retained sample describes survival-conditional detection; it does not estimate the probability that a new mutation survives.

Different strengths within a slot use matched random seeds and founders for a given proposal. This preserves preselection history across strengths for that proposal. A strength whose allele is subsequently lost moves to the next proposal. Slots are independent within each treatment. Each retained trajectory has 2,001 generation-level copy counts. For a recent onset, parents first experience selection at 10 kya; the first offspring generation under this fitness regime is 9,975 years ago.

At the causal coordinate, the statistic is the mean Gamma-SMC posterior probability of a pairwise TMRCA below each cutoff over 1,000 pairs and cutoffs of 1–50 kya. Inference uses flanking neutral sequence variation across the region. Both fixed and segregating replicates use the same coordinate. A call occurs if any 1-kya cutoff inside the specified window passes the one-sided pointwise rank threshold, strictly below 0.05 or 0.01. The independent neutral FPR uses the same rule; these are window-wise detection rates. Each origin has its own 100 calibration neutrals and 100 held-out neutrals, all matched to a 50-kya introduction. The archived neutral proposal audits recorded zero fixed alleles.

Run the full workflow on Linux with `EAS_WORKERS=20 bash scripts/run_eas_causal_50k.sh`. The optional `EAS_PYTHON` selects an existing simulation Python environment through uv. The simulator and decoder must match the SHA-256 hashes in the simulation configuration. Set `EAS_SLIM` and `EAS_DECODER` if the binaries are outside the default locations. The raw directory defaults to `~/sim/eas_causal_50k_20261123` and can be set with `EAS_CAUSAL_RAW`. The simulation phase verifies prior outputs and resumes unfinished slots. After the array finishes, the workflow assembles mass and trajectory data and renders PNG and vector PDF figures. Running `uv run python scripts/report_eas_causal_50k.py report` rerenders them from the assembled portable data.
