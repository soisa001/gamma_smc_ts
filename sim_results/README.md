# Committed validation results

- `minimal`: 200 fixed-standard-coalescent replicates, 100 diploids, 200 kb.
- `n2000_sensitivity`: 100 fixed-standard-coalescent replicates, 2,000 diploids,
  200 kb, used to test discreteness at the intended empirical pair count. This
  recorded run used msprime's then-default JC69 mutation model; current workflow
  code explicitly uses the binary mutation model required by Gamma-SMC.

Per-replicate segregating-site TSVs are excluded from git because they are
reproducibly regenerated by `scripts/run_minimal.ps1`. Manifests, configuration,
rank-calibration tables/metrics, and QC/QQ plots are retained.

These are tree-sequence truth/calibration results. They are not Gamma-SMC decoder
accuracy results; the C++ decoder must be run on Linux, then checked with
`gamma-smc-aou evaluate-decoder`.
